# FUTURE IDEAS — the intake folder

**Drop ideas and prompts here, in whatever form suits you.** Nothing in this folder needs a status,
a template or a tidy-up. It is the inbox.

Work is *tracked* elsewhere, because an idea and a tracked work item are different things: an idea
is what you wanted, a tracked item is what the repository actually does about it.

```
docs/FUTURE IDEAS/          ← you write here, freely
        │
        ▼                   a session audits it against the code
docs/kb/backlog/<note>.md   ← tracked item: real state, real status
        │
        ▼
docs/kb/Project Board.md    ← one screen: FUTURE / IN PROGRESS / COMPLETED / BLOCKED / DEFERRED
```

## The source prompts are kept

They are not deleted when the work is done, and they are not edited to match what shipped. The
reasoning in them is worth more than their accuracy — a tracked note records what was built, and the
prompt records what was wanted. When a prompt is fully delivered, note that at the top of it and
leave it here.
